# Tabs

A horizontal tab navigation component with full keyboard support and ARIA compliance. Tabs can render as links or buttons and support custom styling, add-ons, and label rendering.

The default `variant="segmented"` is for a few peer views. It shares its appearance with [ButtonGroup](/ButtonGroup), but controls content panels rather than a setting. Segmented tabs default to medium labels, medium/large padding, and an xsmall gap.

---

## Props

### Tabs

| Prop            | Type                                        | Default       | Description                                                                 |
| --------------- | ------------------------------------------- | ------------- | --------------------------------------------------------------------------- |
| `aria-controls` | `string`                                    | Required      | ID of the content panel this tab controls                                   |
| `onReorder`     | `(tabId: string, targetId: string) => void` | -             | Enables controlled pointer/keyboard reordering; requires stable, unique IDs |
| `tabs`          | `Tab[]`                                     | Required      | Array of tab configurations                                                 |
| `variant`       | `"segmented" \| "document"`                 | `"segmented"` | Visual selection treatment                                                  |
| `labelSize`     | `Size`                                      | By variant    | Text size for tab labels                                                    |
| `iconSize`      | `Size`                                      | By variant    | Size of tab icons                                                           |
| `tabPadding`    | `Padding`                                   | By variant    | Padding inside each tab                                                     |
| `gap`           | `Gap`                                       | By variant    | Space between tabs                                                          |
| `jssTab`        | `JSS \| (data) => JSS`                      | -             | Custom styles for tabs (can be conditional on selected state)               |
| `labelRenderer` | `(label: string) => ReactNode`              | -             | Custom label rendering function                                             |

### Tab object

| Property        | Type                                           | Default   | Description                                                 |
| --------------- | ---------------------------------------------- | --------- | ----------------------------------------------------------- |
| `id`            | `string`                                       | -         | Stable identity and tab element ID; required for reordering |
| `onRename`      | `(name: string) => void \| Promise<void>`      | -         | Enables inline renaming; throw/reject to show an error      |
| `onContextMenu` | `(event: MouseEvent \| KeyboardEvent) => void` | -         | Right-click, Menu key, or Shift+F10                         |
| `label`         | `string`                                       | Required  | Tab display text                                            |
| `icon`          | `IconType`                                     | -         | Icon displayed with the label                               |
| `href`          | `string`                                       | -         | Link URL (renders as link if provided)                      |
| `onClick`       | `() => void`                                   | -         | Click handler (renders as button if no href)                |
| `selected`      | `boolean`                                      | `false`   | Whether this tab is currently selected                      |
| `addOn`         | `ReactNode`                                    | -         | Additional element (e.g., badge, icon)                      |
| `addOnPosition` | `"start" \| "end"`                             | `"start"` | Position of add-on relative to label                        |

---

Document tabs default to 14px labels, small icons, and a 39px scrolling strip with a bottom divider. They can be used directly as a `Pane` header.

## Tabs as buttons

Omit `href` to render tabs as buttons. Useful for in-page tab switching:

<Column gap="medium">
  <Tabs
    aria-controls="panel-4"
    tabs={[
      { selected: true, label: "Details" },
      { selected: false, label: "Reviews" },
      { selected: false, label: "Related" },
    ]}
  />
</Column>

```js
const [activeTab, setActiveTab] = useState("details");

<Tabs
  aria-controls="content-panel"
  tabs={[
    {
      selected: activeTab === "details",
      label: "Details",
      onClick: () => setActiveTab("details"),
    },
    {
      selected: activeTab === "reviews",
      label: "Reviews",
      onClick: () => setActiveTab("reviews"),
    },
    {
      selected: activeTab === "related",
      label: "Related",
      onClick: () => setActiveTab("related"),
    },
  ]}
/>;
```

## Custom label rendering

Use `labelRenderer` to customize how tab labels are displayed:

<Column>

    tabs={[
      { href: "/Tabs", selected: true, label: "Bold Tab 1" },
      { href: "/Tabs", selected: false, label: "Bold Tab 2" },
      { href: "/Tabs", selected: false, label: "Bold Tab 3" },
    ]}
  />
</Column>

```js
<Tabs
  aria-controls="panel"
  labelRenderer={(label) => (
    <>

    { href: "/featured", selected: true, label: "Featured" },
```

## Custom tab styles

Use `jssTab` for custom styling. It can be a static style object or a function that receives the tab's selected state:

<Column>
  <Tabs
    aria-controls="panel-6"
    jssTab={(data) => ({
      borderBottom: data.selected ? "2px solid cyan" : "2px solid magenta",
    })}
    tabs={[
      { href: "/Tabs", selected: true, label: "Styled Tab 1" },
      { href: "/Tabs", selected: false, label: "Styled Tab 2" },
      { href: "/Tabs", selected: false, label: "Styled Tab 3" },
    ]}
  />
</Column>

```js
// Conditional styling based on selection
<Tabs
  aria-controls="panel"
  jssTab={(data) => ({
    borderBottom: data.selected
      ? "3px solid var(--highlight)"
      : "3px solid transparent",
    backgroundColor: data.selected
      ? "var(--light-highlight)"
      : "transparent",
  })}
  tabs={tabs}
/>

// Static styling for all tabs
<Tabs
  aria-controls="panel"
  jssTab={{ borderRadius: 8 }}
  tabs={tabs}
/>
```

## Keyboard navigation

Tabs support full keyboard navigation:

- **Arrow Left/Right**: Move focus between tabs
- **Enter/Space**: Activate the focused tab
- **Home**: Move to first tab
- **End**: Move to last tab

## Accessibility

The Tabs component follows WAI-ARIA tab patterns:

- Container has `role="tablist"`
- Each tab has `role="tab"` and `aria-controls` pointing to its panel
- Selected tab has `aria-selected="true"`
- Content panel should have `role="tabpanel"` and matching `id`

```js
<Tabs
  aria-controls="settings-panel"
  tabs={tabs}
/>

<div id="settings-panel" role="tabpanel">
  {/* Panel content */}
</div>
```

## Closable document tabs

Use `variant="document"`, stable tab `id` values, and per-tab `onClose`. `title` overrides the label tooltip. Close actions are siblings, never nested buttons; the application owns removal and selection, so a cancelled close does not select another tab. Arrow keys select tabs, Home/End jump, and Delete closes a closable tab. `panelId` can override the shared `aria-controls` for each tab.

## Reordering and renaming

Add `onReorder` to enable native pointer reordering. It receives the moved tab's ID and the ID occupying its destination in the original order. Update your array to commit; otherwise the preview returns to the supplied order. IDs must be unique, nonempty and stable across renames.

- **Alt+Shift+Left/Right**: Move the focused tab, preserving selection.
- **Escape**: Cancel a drag; ordinary arrow navigation is unchanged.
- **F2 / double-click**: Rename a tab with `onRename`.
- **Enter / blur**: Save the trimmed name. Empty or unchanged names close without saving.
- **Escape while renaming**: Discard edits unless a save is pending.

Pressing gently lifts a tab with a 180ms overshoot; releasing settles it back. Reordering starts after 5px, scrolls at strip edges and ignores close buttons. Reduced motion disables animations. Document tabs reveal the full focused/selected tab, including its close button, and translate vertical wheel movement into horizontal scrolling when overflowing. No drag-and-drop dependencies are used.

`onRename` owns the label update. Async saves keep the editor read-only; rejection displays an accessible error. Use [InlineRename](/InlineRename) for the same behavior outside tabs.

```tsx
<Tabs
  variant="document"
  aria-controls="panel"
  onReorder={(id, targetId) =>
    setTabs((tabs) => {
      const next = [...tabs];
      next.splice(
        tabs.findIndex((tab) => tab.id === targetId),
        0,
        ...next.splice(
          tabs.findIndex((tab) => tab.id === id),
          1,
        ),
      );
      return next;
    })
  }
  tabs={tabs.map((tab) => ({
    ...tab,
    selected: tab.id === selected,
    onClick: () => setSelected(tab.id),
    onRename: (label) =>
      setTabs((tabs) =>
        tabs.map((item) => (item.id === tab.id ? { ...item, label } : item)),
      ),
  }))}
/>
```

### Glass tabs

`tabMaterial="glass"` applies the shared material to each tab, including its close action. Use it with `variant="document"` over scrolling content. `material="glass"` treats the whole tab strip as one surface.
