# Tooltip

Supplementary text shown on hover or focus. A tooltip never receives or moves keyboard focus and is not a dialog.

<Row gap="large" padding="xlarge" wrap>
  <Tooltip content="This confirms the action">
    <Button bare color="primary" onClick={() => {}}>
      Hover me
    </Button>
  </Tooltip>
  <Tooltip content="Save document" placement="bottom" align="start">
    <IconButton
      bare
      icon="save"
      color="secondary"
      aria-label="Save document"
      onClick={() => {}}
    />
  </Tooltip>
  <Tooltip
    content="A longer explanation stays inside the viewport without overriding internal selectors."
    align="end"
  >
    <Button bare color="secondary" onClick={() => {}}>
      End-aligned hint
    </Button>
  </Tooltip>
</Row>

```tsx
<Tooltip content="Keyboard shortcut: Ctrl+S" placement="top" align="end">
  <IconButton
    icon="save"
    color="secondary"
    aria-label="Save document"
    onClick={save}
  />
</Tooltip>
```

| Prop         | Default  | Purpose                                                     |
| ------------ | -------- | ----------------------------------------------------------- |
| `content`    | —        | Supplementary text                                          |
| `children`   | —        | A single element that forwards ARIA attributes              |
| `placement`  | `top`    | Preferred `top`, `bottom`, `left`, or `right`; flips to fit |
| `align`      | `center` | `start`, `center`, or `end`                                 |
| `tag`, `jss` | —        | Trigger wrapper element and styling                         |

- Uses native hint popovers, not `dialog.show()`.
- Describes the trigger through `aria-describedby`, preserving existing descriptions.
- Remains visible while the trigger is focused or the pointer is over the trigger/tooltip.
- A short pointer grace period permits moving into the tooltip.
- Escape, Tab from the trigger, and outside clicks dismiss it. Escape leaves enclosing menus and dialogs open.
- Portaled positioning avoids clipping and constrains long text to the viewport. Long paths wrap rather than scrolling horizontally.

Provide an accessible name independently: tooltip text is a description, not an icon button’s only label. Do not hide essential instructions or interactive controls inside a tooltip; use [Popover](/Popover) instead.
