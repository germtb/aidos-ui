# Checkbox

A compact rounded-square checkbox with a native input. The mark is smaller than its hit target; keyboard focus outlines the mark, not the surrounding row.

---

## Props

### Checkbox

| Prop      | Type         | Required | Default | Description                                                                            |
| --------- | ------------ | -------- | ------- | -------------------------------------------------------------------------------------- |
| `checked` | `boolean`    | Yes      | -       | Whether the checkbox is checked                                                        |
| `onClick` | `() => void` | Yes      | -       | Called when checkbox is toggled                                                        |
| `size`    | `Size`       | Yes      | -       | `"small"` (16px mark / 24px target), `"medium"` (20px / 32px), `"large"` (24px / 40px) |

Also accepts standard HTML input attributes.

### StaticCheckbox

| Prop      | Type      | Required | Default | Description                          |
| --------- | --------- | -------- | ------- | ------------------------------------ |
| `checked` | `boolean` | Yes      | -       | Whether the checkbox appears checked |
| `size`    | `Size`    | Yes      | -       | `"small"`, `"medium"`, `"large"`     |

## StaticCheckbox

Use `StaticCheckbox` when you need just the visual appearance without the underlying `<input>` element. Useful when the checkbox is part of a larger interactive component.

<Row padding="medium" gap="large" justify="center" align="center">
  <StaticCheckbox size="small" checked={true} />
  <StaticCheckbox size="medium" checked={true} />
  <StaticCheckbox size="large" checked={true} />
</Row>

```js
// Visual only - no input element
<StaticCheckbox size="medium" checked={isSelected} />

// Used within a custom list item
<ListButtonItem
  headline="Option"
  addOn={<StaticCheckbox size="medium" checked={selected} />}
  onClick={toggleSelection}
/>
```

## With label

Checkboxes are typically paired with labels for better UX:

```js
<Row gap="small" align="center">
  <Checkbox
    id="terms"
    size="medium"
    checked={agreed}
    onClick={() => setAgreed(!agreed)}
  />
  <label htmlFor="terms">I agree to the terms and conditions</label>
</Row>
```

## Accessibility

- Uses native `<input type="checkbox">` for full keyboard and screen reader support
- Visual checkbox is layered over the hidden input
- Focus ring appears on keyboard navigation
- The default checkmark renders immediately, without loading an icon
- `aria-checked` attribute reflects current state
