# Visual system laboratory

This page dogfoods Aidos's surface, navigation, input, and control foundations. Each example uses library components and public props, so the page reflects the system applications actually receive.

---

## Surface placement and elevation

The default card remains the baseline. Tonal cards separate content through color, floating cards use external elevation, and the aurora material adds an atmospheric blue-green surface treatment.

## Atmospheric materials

Materials describe how a surface looks rather than where it belongs. Each treatment adapts to light and dark themes and can be combined independently with a Card elevation variant.
