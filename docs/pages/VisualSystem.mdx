## Materials

Materials describe a surface's appearance independently from its role. Atmospheric presets add a tint; glass shares one treatment for diffusion, highlights, and elevation across components. All treatments follow light and dark themes.

  </Card>

  </Card>

    />
  </Card>
  <GlassMaterialDemo />
</Row>

- **Thin:** 28%/32% light/dark tint and 5px blur; the default glass treatment.
- **Regular:** 38%/42% tint and 8px blur; opt-in extra diffusion.
- **Thick:** 48%/52% tint and 12px blur; opt-in denser diffusion.
- Reduced motion keeps highlights still. Reduced transparency and forced colors replace glass with an opaque surface.

<details>
<summary>Using glass</summary>

Use `material="glass"` on standard components. Their geometry, selection, and focus behavior stay intact; the shared material supplies tint, refraction, highlights, and shadow.

```tsx
<Button material="glass" color="secondary" onClick={save}>Save</Button>
<Card material="glass">{content}</Card>
<TextInput material="glass" value={value} onValueChange={setValue} />
```

`glass()` is the low-level JSS helper. Aidos surfaces attach the refraction enhancement automatically—no render callback or extra layout wrapper.

```tsx
import { Box, glass } from "aidos-ui";

<Box jss={[glass(), { borderRadius: 16 }]}>{content}</Box>
<Box jss={glass("regular")}>{content}</Box>
```

`Button`, `IconButton`, `Card`, `TextInput`, `List`, `Tabs`, and `TabBar` accept `material="glass"`. List rows retain their ordinary styling. `Tabs tabMaterial="glass"` applies glass to individual tabs instead of the strip. Switches use glass by default.

Append JSS overrides after `glass()` when needed. Changing material keeps the same mounted surface and refs. `Composer material="glass"` uses the same helper; `glassThickness` defaults to `"thin"`.

The refraction map is adapted from [Shu Ding's liquid-glass](https://github.com/shuding/liquid-glass) under the MIT license. Browsers without SVG backdrop filters retain the CSS blur.

</details>
